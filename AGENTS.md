# AGENTS.md — machine agent Graphene CI

Этот репозиторий содержит только машинный агент Graphene. Агент является
исходящим gRPC-клиентом и реализует контракт из
`github.com/graphene-ci/graphenepb/v1/agent`.

## Инварианты

- Wire-контракт и его комментарии авторитетнее реализации. Изменение поведения
  сначала делается в `graphenepb`, затем здесь.
- Входящих портов нет. Все RPC инициирует агент.
- Секрет не попадает в protobuf, конфигурационные дампы и логи. Прямое значение
  разрешается только через `GRAPHENE_AGENT_TOKEN`; остальные источники хранят
  только путь к token file.
- `InstructionId` сохраняется транзакционно до любого внешнего side effect.
  Повторно увиденная инструкция никогда не исполняется.
- `Connect.Send` вызывается ровно из одного места. Control events имеют приоритет
  над command output.
- stdout и stderr читаются непрерывно. Transport backpressure не имеет права
  заблокировать pipe дочернего процесса или сделать память неограниченной.
- Artifact загружается во временный файл на том же filesystem и становится
  видимым только через fsync + atomic rename. Upload/download возобновляются по
  offset и всегда завершаются проверкой полного SHA-256.
- v1 поддерживает Linux. Неподдерживаемая платформа должна завершаться явной
  ошибкой до подключения.
- Machine facts собираются только через системные API и linked libraries:
  никаких внешних команд, runtime sockets и повышения привилегий. Dynamic
  utilization относится к OTEL metrics, а не к inventory.
- Чувствительные facts возвращаются только при одновременном разрешении в
  `ReadFacts` и локальной конфигурации. Каждый collector ограничен timeout и
  количеством элементов и возвращает явный per-group status.

## Проверка

Перед передачей изменений обязательны:

```sh
make test
make lint
make build
```

Интеграционные тесты должны проверять протокол через настоящий gRPC transport,
а не только через mocks интерфейсов.
